# Alpenpass Rally

A top-down 2D car race up five Swiss Alpine passes: Grimsel, Susten, Furka, Nufenen and the cobbled Gotthard Tremola.

- Championship (five rounds, points per race) and quick race with track choice
- Tunnels, nitro pickups, black ice, post buses and tractors
- Ghost replay of your best run on each pass
- Adjustable steering sensitivity
- Keyboard (arrows or WASD, Shift for nitro) and on-screen touch controls

Single file, no build step. Open `index.html` in a browser.
